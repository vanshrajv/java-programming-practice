# ☕ Java Programming Practice

A collection of **20 Java programs and projects** created for B.Tech Computer Science and Engineering students. This repository covers important Java concepts from basic programming to Object-Oriented Programming (OOPs), Strings, Packages, Exception Handling, and Multithreading.

## 📚 Topics Covered

- Java Fundamentals
- Classes and Objects
- Constructors
- Inheritance
- Method Overloading and Overriding
- String Handling
- Encapsulation
- Access Modifiers
- User-Defined Packages
- Predefined Packages
- Exception Handling
- Multithreading

## ⚙️ How to Run

**Step 1:** Install Java JDK.

**Step 2:** Clone this repository.

```bash
git clone https://github.com/Vanshrajv/java-programming-practice.git
```

**Step 3:** Open the project folder.

**Step 4:** Open any Java program in VS Code.

**Step 5:** Compile and run:

```bash
javac PrimeNumber.java
java PrimeNumber
```

Replace `PrimeNumber` with the class name of the program you want to run.
